# Evidence

The evidence tree separates frozen study outputs from derived release views.

- `comparative/core_analysis.json` contains the core behavior, intervention,
  remediation, capability, and causal-exchange analyses.
- `comparative/jlens_readout_summary.json` contains the raw, matched,
  common-base, and fixed-input readout results.
- `action-use/phase3_confirmation.json` contains the six-lineage response-format
  confirmation, factorial contrasts, and remedy gates.
- `forecasting` contains aggregate analyses plus raw fixed-investigator prompts,
  responses, prediction receipts, and freeze records.
- `tables` is regenerated by the root release scripts and provides the shortest
  human-readable route to checkpoint and gate decisions.

The JSON files are evidence; the CSV and Markdown files are views. See
[`../docs/EVIDENCE_GUIDE.md`](../docs/EVIDENCE_GUIDE.md) for claim-level
navigation.
