# Frozen configurations

Configurations are grouped by study:

- `comparative` contains cohort-selection and retained Jacobian-lens metadata.
- `action-use` contains fresh-lineage training recipes, scenario manifests,
  parser contracts, causal gates, and confirmation freezes.
- `forecasting` contains checkpoint inventories, evidence/query plans, outcome
  freezes, and follow-up contracts.

Some files are historical development records rather than active confirmation
specifications. The active freeze sequence is summarized in
[`../docs/STUDY_CHRONOLOGY.md`](../docs/STUDY_CHRONOLOGY.md).
