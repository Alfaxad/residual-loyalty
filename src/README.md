# Scientific source

The source tree preserves the study-era code by research phase.

- `comparative`: matched construction, behavior and capability evaluation,
  readouts, activation/writer interventions, Jacobian-lens fitting, component
  exchange, remediation, and analysis.
- `action-use`: fresh paired lineages, response-format generation and parsing,
  factorial training, diversified remedies, causal follow-ups, and confirmation
  analysis.
- `forecasting`: evidence collection and ranking, fixed-investigator forecasts,
  held-out outcomes, follow-ups, and sensitivity analysis.

The files retain their original study-root conventions and are not presented as
a single installable package. Public release helpers live in `../scripts`.
Account-specific launch wrappers, operational ledgers, and report code that
embedded private infrastructure accounting are excluded; scientific worker and
analysis code is retained.
